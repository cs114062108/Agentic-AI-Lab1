## Q1: Multi-turn Course-planning Chatbot

### Q1.1: Explain how your program stores and reuses the conversation history.
I wrote the class `ChatSession` to maintain a chat session of an individual user. Each `ChatSession` has a `__histories` object. When initialized, it adds the agent instruction and the user's name as system information to `__histories`. When the method `send_chat` is called, it makes a copy of `__histories`, append user's prompt to the copy, and send the history copy to the LLM. If the LLM responded with no error, the histories is then copied back to `__histories` with the LLM's response included.
